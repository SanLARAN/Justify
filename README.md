# Justify

Бесплатный музыкальный плеер для Windows: поиск и воспроизведение с Зайцев.нет, SoundCloud, YouTube Music и Audius, плейлисты и лайки, перенос музыки из Яндекс Музыки и Spotify, эквалайзер, «Моя волна», тексты песен с переводом, скачивание для офлайна, прокси и VPN, голосовое управление «Джасти».

Сайт: **[sanlaran.github.io/Justify](https://sanlaran.github.io/Justify/)**

## Скачать

**[⬇ Скачать Justify для Windows](https://github.com/SanLARAN/Justify/releases/latest/download/Justify-win64.zip)** (Windows 10/11, 64-бит, ~170 МБ)

Распакуйте архив в любую папку и откройте `Justify.exe`, установка не нужна. Если Windows SmartScreen покажет предупреждение, нажмите «Подробнее» → «Выполнить в любом случае». Медиатека, плейлисты и настройки хранятся в `%APPDATA%\Justify`.

## Обновления

Этот репозиторий — источник автообновлений Justify. Новые версии публикуются в [Releases](../../releases): Justify сам проверяет их раз в несколько часов, скачивает в фоне и устанавливает при выходе из программы. Если новая версия не запустится, Justify вернёт предыдущую.

Если у вас версия 1.5.0 или старше, один раз укажите источник: **Настройки → Обновления → источник** — `SanLARAN/Justify`.

В каждом релизе два архива: `Justify-win64.zip` — полная программа для новой установки, `Justify-<версия>-update.zip` — обновление для уже установленного Justify (папка `resources/app`), его Justify скачивает сам.
